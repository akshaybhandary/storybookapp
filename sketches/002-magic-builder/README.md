## Variant: Magic Builder (action-first, app-like)

### Design stance
The product IS the hero — the book builder sits above the fold; the site feels like a magical app, not a store.

### Key choices
- Layout: centered glassmorphic builder card in the hero (name, age, photo dropzone, theme chips)
- Typography: Fredoka throughout; gradient headlines
- Color: deep indigo night-sky with twinkling stars, warm gold/pink gradients
- Interaction: working theme picker + "Make my book" that renders a personalized confirmation

### Trade-offs
- Strong at: instant engagement, conversion speed, demoing the 5-minute promise
- Weak at: traditional gift-buyer trust cues; dark theme is unusual for kids' retail

### Best for
Millennial parents on mobile, TikTok/IG traffic, impulse "let's try it" sessions.
